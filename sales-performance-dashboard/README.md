# Sales Performance Dashboard

**Tools:** Microsoft Excel

![Dashboard](excel-sales-dashboard.jpg)

## Goal

Analyze sales by date, region and product.

## What I did

- Built an interactive dashboard with Pivot Tables, Pivot Charts, Slicers and a Timeline

## Findings

- South was the highest-selling region (about 1.24M).
- Backpack was the highest-revenue product (about 666K).
